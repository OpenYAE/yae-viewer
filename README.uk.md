# YAE Viewer

[English](README.md) · [Русский](README.ru.md) · [Українська](README.uk.md)

Переглядач ресурсів *You Are Empty* (2006) та *Instinct* (2007), що працює в браузері: вкажіть теку з
розпакованими файлами гри й дивіться рівні з лайтмапами, колізіями та навігаційною сіткою, моделі -
зі скелетом та анімаціями. Файли нікуди не завантажуються, все читається й розбирається в браузері.
Частина [Project Empty](https://github.com/OpenYAE).

**Онлайн:** https://openyae.github.io/yae-viewer/ (публікується з цього репозиторію через GitHub
Pages). Встановлюється як PWA і після першого відкриття працює офлайн.

## Як користуватися

1. **Add folder** - оберіть теку з розпакованими ресурсами гри (`gameres` або будь-яку теку з
   `maps/`, `models/`, `textures/`, `materials/`). Браузери на Chromium один раз запитують доступ на
   читання й запам'ятовують теку в *Open recent*; інші читають теку через звичайний діалог вибору
   файлів. Теку, рівень або модель можна й просто перетягнути у в'юпорт.
2. **File list** показує лише те, що в'юер відкриває - рівні `.ds2` і моделі `.ds2md` - у їхніх
   теках. Усе супутнє знаходиться само: колізія `.ds2cm2`/`.ds2cm`, навігаційна сітка `.ds2aim`
   (`_rebuilded` бажано, як її завантажує гра), сторінки лайтмапів `<level>_lm_N.tga`, шаблони
   матеріалів `.mat` і всі текстури, які називають меші (`textures/**/*.dds`, `.tga`).
3. Відкритий файл розгортається у список вмісту. Клік по рядку виділяє об'єкти в дереві **Objects**.  
   Можна обирати кілька об'єктів, кадрувати (`F` або подвійний клік), ховати й фільтрувати.  
   Для моделей доступні **Skeleton**, **Transform** і **Animations**.
4. Плеєр під в'юпортом програє кліп; кнопка таймлайну відкриває dope sheet - спочатку доріжки
   обраної кістки, потім усіх анімованих - з плейхедом, переходом по ключах, onion skin і
   прив'язкою до кадру. Ключі читаються з файлу й не редагуються.

### Керування в'юпортом
- Орбіта - миша  
- Політ - `WASD` / `QE` (Shift - швидше)  
- Вибір - клік, кадрування - подвійний клік  
- Пресети камери: `0` (perspective), `7` (top), `1` (front), `3` (left), `Home` - скидання  

### Режими рендеру
**DS2 Render** (картинка гри: diffuse × lightmap × 2 або diffuse × вершинне світло × 2 у display-просторі), 
**Lit** (світло рівня через three.js), Albedo, Normals, Lightmap, UV checker, Wireframe.  
У налаштуваннях можна вмикати/вимикати лайтмапи, світло, тіні, навмеш, колізію, сітку та гізмо скелета,
а також завантажити HDR-тло (`.exr`/`.hdr` - кнопка **Load HDR** або просто перетягніть файл у в'юпорт).

### Підтримувані формати
`.ds2` (геометрія рівня, версія 0.8), `.ds2md` (моделі 1.0 і старі 0.6),
`.ds2cm`/`.ds2cm2`, `.ds2aim`, `.mat`, `.dds` (DXT1/3/5, програмне декодування там, де GPU не має
S3TC), `.tga`, `.png`/`.jpg`.


## Розробка

```bash
npm ci
npm run dev        # dev-сервер Vite на http://localhost:5180/yae-viewer/
npm run build      # перевірка типів + збірка в dist/
npm run preview    # роздача dist/
```

`VITE_BASE` задає шлях, під який збирається сайт (workflow Pages передає `/<репозиторій>/`).
