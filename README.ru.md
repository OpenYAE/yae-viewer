# YAE Viewer

[English](README.md) · [Русский](README.ru.md)

Просмотрщик ресурсов *You Are Empty* (2006) в браузере: перетащите на страницу модель, уровень,
коллизию или навмеш из своей копии игры и смотрите с текстурами, лайтмапами, скелетом и
анимациями. Ничего никуда не загружается, файлы разбираются в браузере. Часть
[Project Empty](https://github.com/OpenYAE).

**Онлайн:** https://openyae.github.io/yae-viewer/ (публикуется из этого репозитория через GitHub Pages).

## Что открывает

| Что бросить | Форматы |
|---|---|
| Модель или уровень | `.ds2md` (модели со скелетом и анимациями), `.ds2` (геометрия уровня), `.glb`, `.gltf` |
| Слои поверх | `.ds2cm`, `.ds2cm2` (коллизия, во второй версии с материалами), `.ds2aim` (навмеш ИИ) |
| Текстуры | `.png`, `.jpg`, `.tga`, `.dds` и лайтмапы уровня |

Где это лежит в игре: модели в `gameres/models/`, уровни в `gameres/maps/`, текстуры в
`gameres/textures/`. Ресурсы игры в репозиторий не входят.

## Запуск локально

Страница состоит из трёх файлов: `index.html`, `styles.css`, `app.js`; three.js подгружается с CDN
через import map. ES-модули не грузятся с `file://`, поэтому папку нужно отдать сервером:

```bash
python3 -m http.server 8080      # затем открыть http://localhost:8080/
```

## Откуда код

Просмотрщик вырос внутри [YAE SDK](https://github.com/OpenYAE/yae-sdk), где его замороженная копия
(`viewer.html`) остаётся эталоном поведения для вьюпорта редактора. Этот репозиторий — копия,
которая развивается как публичный просмотрщик. Следующая итерация — переработка интерфейса,
список в [TODO.md](TODO.md): одно поле загрузки для всех типов файлов, убрать экспорт анимации и
тестовые контролы, новый дизайн.
